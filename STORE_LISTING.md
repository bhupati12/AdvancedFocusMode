# Chrome Web Store Listing Draft

## Title

Advanced Focus Mode for Developers

## Short description

Developer-focused focus mode with sessions, distraction shielding, task stack, recovery, budgets, and presentation mode.

## Full description

Advanced Focus Mode for Developers helps you stay on one concrete work item at a time.

It is built for developers who want:

- a fast new-tab focus dashboard
- keyboard-first session control
- developer work modes
- project-aware sessions
- task stacking and notes
- distraction shielding and budgets
- context capture and restore
- replay, forensics, and reports
- demo mode and presentation mode
- a clean tab surface for distraction-free work

### Highlights

- Start, pause, finish, skip break, or reset a session
- Choose a mode such as code sprint, debug bash, review block, architecture block, writing block, or planning block
- Capture the current work context and restore it later
- Shield distracting sites and manage host budgets
- Review session replay, history, and activity logs
- Export or import a backup file
- Open a clean tab for simple focused work
- Present the product with a guided demo mode

### Privacy

The extension is designed to be local first. It stores focus data in the browser and does not use a backend in the current build.

## Permissions explanation

- `tabs`: used for capturing and restoring context, tracking focus changes, and opening focus pages
- `storage`: used for local sessions, notes, budgets, and settings
- `alarms`: used to keep the timer accurate
- `notifications`: used for focus reminders
- `declarativeNetRequest` and host access: used for distraction shielding
